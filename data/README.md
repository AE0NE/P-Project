# 데이터 관리

원본 문서, 전처리 결과, 라벨 데이터는 기본적으로 Git에 올리지 않습니다.
로컬에서는 `raw/`, `processed/`, `annotations/`, `splits/` 등으로 구분할 수 있습니다.

- 카드사 공식 자료의 상품명·상품 ID·출처 URL·수집일·문서 버전·SHA-256을 기록합니다.
- 같은 상품의 HTML·PDF·개정본은 한 데이터 분할에 배치합니다.
- 상품 12종을 학습 7종·검증 2종·시험 3종으로 나누고 분할을 고정합니다.
- 라벨은 TARGET, RATE, SPEND, LIMIT, SPEND_EXCL, BENEFIT_EXCL을 사용합니다.
- 원문에서의 문자 오프셋과 출처 위치를 보존해 근거를 확인할 수 있도록 합니다.
- 개인정보나 실거래 데이터를 수집하지 않습니다.
- 원문·가공 데이터 공개 전 이용 조건을 확인합니다. 공개가 어려우면 수집 절차·출처 목록·합성 예시를 제공합니다.

공개 가능한 파일은 검토 후 `.gitignore` 예외를 좁은 경로로 추가합니다.
`git add -f`로 원본 자료 전체를 강제로 올리지 않습니다.
