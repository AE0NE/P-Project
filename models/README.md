# 모델 및 실험 산출물 관리

체크포인트·가중치·ONNX·양자화 모델은 기본적으로 Git에 올리지 않습니다.
코드 저장소에는 학습·평가 코드와 설정, 모델 버전·출처·이용 조건을 관리합니다.

KoELECTRA-Small은 초기 비교 후보이며, 최종 모델은 추출 성능·CPU 처리시간·메모리로 결정합니다.
공개 배포 시 기반 모델과 학습 데이터의 이용 조건을 확인하고 모델 카드에 다음을 기록합니다.

- 기반 모델·토크나이저의 정확한 버전과 라이선스
- 학습 데이터 구성·분할 원칙·라벨 정의
- 학습 설정·코드 커밋·재현 방법
- 수정 전 예측 지표와 Baseline, 실행 하드웨어
- 알려진 오류·지원 범위·사람의 검토가 필요한 사례

가중치 배포 경로와 형식은 모델 확정 후 팀에서 정합니다.
